The Wiki · card tools

Every card is a folder inside cards/ holding a card.json and an optional picture (art.png, 700×500 works well). Copy cards/_TEMPLATE, rename the folder, edit the JSON, then press Reload cards. Folders starting with _ are ignored.

{
  "id": "my-card",            // unique, lowercase-with-dashes
  "name": "My Card",
  "rarity": "common",         // common | uncommon | rare
  "icon": "⭐",               // shown if there's no picture
  "description": "One sentence about what it does.",
  "image": "art.png",
  "modifiers": [
    { "stat": "damage", "op": "mul", "value": 1.25 },  // ×1.25 = +25%
    { "stat": "ammo",   "op": "add", "value": 1 }      // +1
  ]
}
